# 交付路线图

> 原则：**每个模块结束时项目必须可运行、可演示、类型检查与构建通过**；未经确认不进入下一模块。

---

## 0. 工作方式

每个模块的交付包含 6 件事：

1. **代码**：按 [目录规范](06-directory.md) 落位，模块化、类型完整。
2. **自测**：`pnpm typecheck && pnpm lint && pnpm build` 通过；关键路径手动跑一遍。
3. **验收清单**：逐条对照本文件的「出口标准」，给出 ✅/⚠️/❌。
4. **演示脚本**：3–5 步说明如何在本地点出效果（含账号、URL）。
5. **变更摘要**：新增/修改文件清单、数据库变更、环境变量变更。
6. **确认点**：列出下一模块范围与需要你拍板的选项，等你确认。

**全局完成定义（DoD）**

- [ ] 无 `any`、无未处理 Promise、无 console error。
- [ ] 所有异步区域有 loading / empty / error / success 四态。
- [ ] 375px 宽度无横向滚动，主要操作单手可达。
- [ ] 新增接口有 Zod 校验、鉴权、错误码、限流。
- [ ] 涉及敏感数据的功能有权限校验与审计。
- [ ] 文档（API/页面/环境变量）同步更新。

## 2. M1 · 工程底座

**范围**

- Next.js 15 + TS strict + Tailwind 4 + shadcn/ui 初始化；设计令牌（色板/字体/圆角/动效）。
- `src/lib/env.ts`（Zod 校验）、`src/server/db.ts`、`withApi` 错误处理骨架、`/api/health`。
- Prisma 迁移执行 + 种子数据（2 用户、3 品牌、48 单品、标签、6 方案、8 帖子、敏感词）。
- 邮箱注册/登录/登出（Auth.js Credentials + bcrypt），会话守卫，`/login` `/register` `/onboarding`。
- 全局布局：Header、BottomTab、Footer、Toaster；首页（Hero + 三入口 + 精选 + 社区预览）。
- 衣橱只读：`/studio` 左栏 + `/api/v1/garments` + facets + 骨架/空态。
- 占位图生成脚本（sharp），保证离线可看。

**出口标准**

- [ ] `pnpm install && pnpm db:push && pnpm db:seed && pnpm dev` 一次跑通。
- [ ] 未登录访问 `/studio` 跳登录；登录后回跳。
- [ ] 衣橱可按类别/颜色/风格/季节筛选，URL 可分享，刷新保持。
- [ ] 首页移动端首屏三入口可见，Lighthouse Performance ≥85。
- [ ] `pnpm build` 通过，无 TypeScript 错误。

**演示**：首页 → 注册 → 引导 → `/studio` 浏览衣橱并筛选。

## 3. M2 · 自由搭配 Studio

拆三个可运行切片：

### M2a 上传与授权

- 上传组件（拖拽/选择/移动端相机）、`react-easy-crop` 裁剪旋转、EXIF 转正。
- 预签名直传（local 驱动 + S3 驱动）、complete 校验、缩略图、敏感图加密。
- 人脸授权弹层 + `Consent` 记录 + 撤回入口（最小版）。
- 上传状态机：idle → cropping → uploading → processing → ready / error。

**出口**：上传成功得到 `mediaId`；未勾选授权无法上传；刷新后仍可看到自己的底图。

### M2b 画布与自有衣服

- 衣橱点击/拖拽加入、槽位规则（连衣裙互斥）、图层排序、删除、撤销重做。
- 画布归一化 transform、移动端手势、键盘微调。
- 自有衣服上传 → `Garment(DRAFT)` → 抠图任务（Mock provider：亮度阈值 + 边缘羽化）→ `READY`。
- 自动保存草稿（debounce 800ms）。

**出口**：搭 4 件并调整位置，刷新后布局误差 <1%；自有衣服 30s 内出现在「我的衣服」。

### M2c 生成与结果

- `POST /outfits/:id/generate` + 任务轮询 + SSE（可选）+ 进度阶段文案。
- Mock Provider：sharp 按槽位比例合成 + 阴影 + 轻调色；降级链与重试。
- 结果页：效果图、单品清单（完整字段）、重新生成、下载（签名 URL）、保存、分享草稿帖。
- 失败态：错误码 → 人话 + 重试 + 「使用预览版」。

**出口**

- [ ] 全链路 ≤8 次点击；Mock 生成 P95 <3s。
- [ ] 断网重试、供应商 500 降级、超时三种失败路径均有 UI。
- [ ] 下载文件可打开且分辨率 ≥1024×1365（3:4）。
- [ ] 分享后草稿帖带封面、关联方案、标签。

## 4. M3 · AI 推荐

**范围**

- `/recommend` 表单（场景 + 可选条件）、示例 chips、校验。
- 场景解析：规则引擎（关键词/场合/正式度/季节）+ Mock LLM；`parsed` 展示与可编辑。
- 召回：类别 × 季节 × 风格 × 预算 × 禁忌色；分面统计用于「无结果」建议。
- 选品：`MockLLM`（模板 + 随机种子）与 `RuleBasedStylist` 双实现；Zod 严格校验。
- 结果页：风格标题、理由、单品清单 + 每件理由、建议/避雷、预算合计与超支提示。
- 异步效果图、换一套（排除已选）、收藏、保存、分享。
- 额度：每日 20 次推荐 / 5 次换一套。

**出口**

- [ ] 10 条不同场景输入，输出组合均合法（无两条裤子、无连衣裙+上下装）。
- [ ] 预算/禁忌色为硬约束，违反率为 0。
- [ ] 文字结果 P95 <3s（Mock），图片异步不阻塞。
- [ ] 换一套后单品重合率 <40%。

## 5. M4 · 讨论区

**范围**

- 信息流（推荐/最新/关注）、瀑布流卡片、无限滚动、骨架。
- 发帖编辑器：图片 1–9、标签、关联方案、预览、草稿。
- 敏感词（Aho-Corasick）+ 图片审核 Mock + 先审后发（新用户）。
- 帖子详情、评论（一级 + 回复）、点赞/收藏/关注（乐观更新）。
- 标签页、搜索（帖子/用户/单品）、举报。
- 热度计算 + Cron 重算。

**出口**

- [ ] 发布含敏感词内容被拦截并高亮。
- [ ] 审核中帖子仅作者可见；通过后进入信息流。
- [ ] 点赞并发/重复点击计数正确；删除帖子后各列表一致。
- [ ] 举报进入后台队列（M5 处理）。

## 6. M5 · 个人中心 · 隐私 · 后台

**范围**

- `/me` 概览、我的搭配/收藏/帖子、设置（资料/偏好/密码）。
- 隐私中心：授权记录、撤回并删图（级联对象存储）、单图删除、数据导出（异步 JSON）、注销（30 天冷静期）。
- 管理后台：举报处理、帖子下架/恢复、商品 CRUD/CSV 导入、任务监控与重试、敏感词管理。
- 通知中心（生成完成/互动/审核结果）。

**出口**

- [ ] 撤回授权后 5 分钟内人脸对象不存在，任务创建返回 `CONSENT_REVOKED`。
- [ ] 导出文件包含用户资料/方案/帖子，24h 过期。
- [ ] 管理员下架帖子后作者收到通知，详情显示「已移除」。
- [ ] 所有管理操作可在 `AuditLog` 查到。

## 7. M6 · 生产化

**范围**

- BullMQ Worker 落地（并发、重试、死信、优雅退出）、`WORKER` Dockerfile。
- S3/R2 存储 + CDN + 签名 URL；MinIO 本地联调。
- 真实 Provider：Fashn（首选）、Replicate IDM-VTON（备选）、Webhook 校验；密钥管理与成本日志。
- 可观测性：pino 结构化日志、requestId 贯通、关键指标、Sentry（可选）。
- 测试：单测覆盖服务与降级链、Playwright E2E 主流程。
- 部署：Vercel + Neon + Upstash + R2 方案文档；Docker Compose 一键起。
- 安全加固：CSP、HSTS、限流完善、依赖审计。

**出口**

- [ ] 无 Redis 时 `inline` 正常；有 Redis 时任务可跨进程、可重放。
- [ ] 真实供应商失败自动降级，用户无感（有角标）。
- [ ] `docker compose up` 后 5 分钟内可完成一次生成。
- [ ] CI 全绿；核心服务单测覆盖率 ≥70%。
